Each morning

A scheduled batch pipeline. No persistent server, deterministic gating, and zero recurring cost.

Collect Ingests university boards, institutional applicant portals, and RSS feeds.
Read Extracts each posting's deadline, supervisor, visa terms, and open status.
Sort Applies routing rules: non-US predocs to Telegram, the rest to the board.
Deliver Dispatches Telegram cards, publishes to X, and updates this registry.
