What you need to do (the full steps are in SETUP_GUIDE.md):
1. Switch off the old bot first. In your predoc-bot repository, open Actions and disable both workflows. Otherwise the two bots fight over your Telegram messages and you get every position twice.
2. Create a new private repository called predoc-pipeline and upload the unzipped files.
3. Create the two automatic jobs by hand (Add file → Create new file). Name them .github/workflows/pipeline.yml and .github/workflows/telegram.yml, and paste in the contents of the two files I sent.
4. Allow the jobs to save their data: Settings → Actions → General → "Read and write permissions".
5. Add two secrets: TELEGRAM_BOT_TOKEN (same token as before) and TELEGRAM_PUBLIC_CHANNEL_ID. The second one is your chat id, the same number you used as TELEGRAM_CHAT_ID. Note the new name.
6. Run it once from Actions. The first run sends every position that's open right now, in numbered lists of 6. After that you only get new ones.
